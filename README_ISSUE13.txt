ISSUE 12 대비 수정한 부분
1. 모든 프로젝트의 왼쪽 정보열과 오른쪽 이미지/PPT 열을 같은 높이의 그리드로 정렬.
2. 대표 이미지의 16:9 비율, 캡션 높이, PPT 헤더·썸네일·조작부 간격을 통일.
3. 모든 프로젝트 PPT 헤더에 「슬라이드 크게 보기 ↗」 버튼 추가. 클릭 시 첫 장 확대.
4. PPT 좌/우 스크롤 버튼의 크기를 키우고, 확대 방법을 한국어로 명시.
5. 크레딧 16개 선택 메뉴 유지. PREV / NEXT를 대비가 높은 흑백 버튼으로 변경.
6. 「전체 크레딧 보기 ↗」를 확실한 클릭 버튼으로 변경.
7. 제목, 서체, 사진, 프로젝트 내용, 기존 기획서, 사이트 URL 및 코드는 유지.

주의: 기존 일부 원본 프로젝트 이미지는 GitHub 원격 주소를 불러옵니다. 인터넷 연결이 필요합니다.
